AI Trading 212

Market-data database maintenance, integrity verification and controlled Google Drive storage, operated through private GitHub workflows.

What this application does

AI Trading 212 helps its owner maintain and verify a historical market-data database. GitHub Actions runs controlled workflows, and the owner's Google Drive stores database objects, snapshots and audit records.

Maintain data

Acquire and reconcile daily market data with historical source records.

Verify generations

Check database integrity, calculation results and certified backups.

Manage storage

Retain required database versions and clean obsolete revisions with the owner's authorization.

Why Google Drive access is needed

The application's OAuth permissions allow it to read, create, update and organize the owner's database files and revisions. When specifically authorized, the application can also permanently delete obsolete revisions as part of verified cleanup.

OAuth access is solely for authorized database maintenance. This informational website does not collect Google Drive files or handle account credentials.
